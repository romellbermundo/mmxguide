# Mega Man X Field Guide

**[Open the X1 guide](https://romellbermundo.github.io/mmxguide/)**

A compact, mobile-first reference for the **Mega Man X** series. The first release focuses on **Mega Man X1**, with a recommended eight-boss route, each boss's weapon weakness, and the four armor capsule locations. Designed to be easy to scan during gameplay.

## Available games

- **X1:** Boss order, weaknesses, and armor parts.
- **X2, X3, X4:** Tabs are visible as placeholders; guides have not been created.

## Design

- One compact, responsive page for X1, without accounts, dependencies, or a build step.
- Bosses listed in recommended order from first to last.
- Armor capsule locations listed separately; Heart Tanks and Sub Tanks intentionally omitted.
- Passwords omitted because they depend on game progress.

## Run locally

Open `index.html` in a browser. The site uses only HTML and CSS.
